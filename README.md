# Globant Piscine

Projects developed as part of the collaboration between Globant and 42 Málaga.

The programme consisted of a series of full-stack development challenges designed to put our programming skills into practice.

This repository contains the work I completed during the one-week programme. Although I didn't manage to complete everything, it was a valuable learning experience that allowed me to gain new knowledge and develop my skills in a short period of time.
